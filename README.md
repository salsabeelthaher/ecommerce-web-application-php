# E-Commerce Web Application

This project is a simple e-commerce web application developed using PHP and MySQL.

The system allows users to browse products, add items to the shopping cart, and complete purchases using PayPal payment integration. It also includes an admin dashboard for managing products and store data.

## Key Features

- **Product Catalog:** Connected seamlessly to a MySQL database for real-time inventory and item updates.
- **Shopping Cart & Checkout:** Add/remove items with dynamic total calculation.
- **User Authentication:** Secure user login and registration forms.
- **PayPal Payment Integration:** Smooth checkout flow for online credit card and account transactions.
- **Admin Dashboard:** Full management suite to monitor store analytics, view system performance, and control content.
- **Category & Item Management:** Comprehensive CRUD operations for managing product categories and inventory listings.

---

## Admin Panel Capabilities

The admin panel allows administrators to:

- View high-level store statistics and performance metrics
- Create, update, and manage product categories
- Add, edit, and delete store products
- Monitor transaction logs and orders
- Analyze system data through intuitive data tables and visualization charts

---

## Technologies Used

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Integrations:** PayPal SDK / Payment Gateway API
